Get Nova

One requirement: Python 3.10 or newer. Zero dependencies — the entire toolchain is stdlib-only.

Install in 30 seconds

git clone https://github.com/sandeepvarma9902/nova-lang.git
cd nova-lang
./nova run examples/hello.nova     # Hello, Nova!

No pip install. No build step. No toolchain maze — the thing Nova was built to kill.

Your first program

// hello.nova
let target = "Nova"
print("Hello, " + target + "!")
./nova run hello.nova
# Hello, Nova!

The one command

Everything lives behind nova:

nova run app.nova              # run a program (or .nvb bytecode)
nova check app.nova            # type-check; diagnostics as JSON
nova fmt app.nova              # canonical formatting
nova lock app.nova             # pin imports by hash
nova build --emit-bytecode     # compile to portable .nvb
nova dom app.nova -o app.html  # components -> self-contained HTML
nova deploy --target docker    # local | docker | aws | gcp
nova eval suite.json           # eval harness for ai fns
nova lsp                       # language server (editor support)
nova migrate --from java|jsx   # experimental mechanical migrator

Editors

The Nova VS Code extension ships a TextMate grammar, snippets, and an LSP client wired to nova lsp for real diagnostics and hover. See editors/vscode/README.md in the repo.
