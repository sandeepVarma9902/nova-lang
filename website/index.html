Why Nova

Java and React come from two different worlds — and each one got something deeply right. Java gave us safety: static types, real modules, write-once-run-anywhere. React gave us composition: components, declarative UI, state you can actually reason about. But Java drowned its strengths in boilerplate and null pointers, and React left you guessing about types, hook rules, and async.

Nova refuses the trade-off. It takes every strength from both — Java's discipline, React's soul — fixes everything that became a con, and fuses them into a single programming language. Your UI, your API, your streams, your deployment: one language, frontend to backend, designed from day one for AI to write and humans to trust.

Java, minus the pain

Static typing with inference. Classes, interfaces, explicit modules. Portable bytecode. No null. No checked-exception ceremony. No 40-line POJO. No classpath hell. Everything Java promised about safety — delivered.

React, minus the footguns

Everything is a component. Type-checked declarative views. Immutable props, unidirectional data flow. Compiler-managed state — no rules of hooks. No prop drilling. No undefined is not a function. Everything React promised about UI — delivered.

// A Nova component: Java's types holding React's model.
component Counter(title: String) {
  state count: Int = 0          // no hooks, no rules-of-hooks. The compiler owns this.

  view {
    <div>
      <h1>{title}</h1>
      <p>{count}</p>
      <button onClick={count = count + 1}>Increment</button>
    </div>
  }
}

effect fn main() {
  let app = render(Counter(title: "Clicks"))
  app.fire("onClick")           // state 0 -> 1, re-renders. That's the whole framework.
}

Inherit the best. Fix the rest.

Nova takes what Java and React got right, surgically removes what they got wrong, and adds what neither ever had: a language designed for AI to write.

From Java inherited

Static typing with inference, classes and interfaces, explicit modules, and write-once-run-anywhere via NovaVM bytecode. The discipline — without the 40-line POJO.

From React inherited

Everything is a component. Type-checked declarative views, immutable props, unidirectional data flow. The model — without the framework.

For AI native

One obvious way to write anything. No implicit conversions, no operator overloading. Compiler errors as structured JSON with fix hints — built for AI consumers, not just humans.

Null is gone fixed

Option[T] with compiler-enforced handling. The billion-dollar mistake is a compile error now, not a 3 a.m. page.

Errors without ceremony fixed

Result[T, E] plus the ? operator. Failure lives in the signature — no checked-exception tax, no silent undefined.

Async, enforced fixed

The compiler tells you what should be async (E_ASYNC_BLOCKING). Single-threaded by default, structured task pools when you opt in. You stop guessing.

Secure by construction platform

No eval primitive exists. IO only through explicit capabilities. Checked integer arithmetic. Dependencies pinned by hash.

Streams built in platform

First-class pub/sub with Kafka-style topics, consumer groups and offsets. In-memory locally, real Kafka provider when you deploy.

Deploy from the language platform

app.nova declares threading, secrets, cron and targets. nova deploy --target docker|aws|gcp — the manifest is the ops doc.
