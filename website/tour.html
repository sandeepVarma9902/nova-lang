The tour

Thirteen stops, zero fluff. Every snippet below is real Nova — copy it, run it with nova run, break it, learn.

1. Values with inference

Statically typed like Java. Terse like the language Java wishes it was. let infers; annotate when it helps the reader.

let greeting: String = "Hello"
let target = "Nova"        // inferred: String
let year: Int = 2026
let pi = 3.14159           // inferred: Float
// year = "2027"           // E_TYPE: the compiler says no. Good.

2. Functions are pure by default

No effects unless you declare them. A plain fn cannot touch the network, the disk, or your state — the checker proves it.

fn add(a: Int, b: Int) -> Int {
  return a + b
}

effect fn save(path: String, data: String, io: IO) {
  writeFile(path, data, io)   // needs the IO capability, passed explicitly
}

3. There is no null

The billion-dollar mistake doesn't compile. Absence is Option[T], and the compiler forces you to handle both arms.

fn findUser(id: Int) -> Option[String] {
  if id == 1 { return Some("Ada") }
  return None
}

match findUser(7) {
  Some(name) => print("Found: " + name),
  None       => print("Not on the list")   // you cannot forget this arm
}
// null          // E_NO_NULL: "Nova has no null. Use Option[T]."

4. Errors without ceremony

Fallible functions return Result[T, E]. The ? operator propagates failure; the happy path stays linear.

effect fn fetchUser(id: Int) -> Result[String, String] {
  if id == 1 { return Ok("Ada") }
  return Err("user " + str(id) + " not found")
}

effect fn greetUser(id: Int) -> Result[String, String] {
  let name = fetchUser(id)?   // Err returns early, automatically
  return Ok("Hello, " + name + "!")
}

5. Data classes in one line

Java's 40-line POJO — fields, constructor, equality, readable printing — is a single declaration.

data class Point(x: Float, y: Float)

let p = Point(x: 1.0, y: 2.0)
print(p == Point(x: 1.0, y: 2.0))   // true

6. Components, minus the footguns

React's model with Java's types. Props are typed parameters and immutable. state is compiler-managed — no hooks, no rules-of-hooks, order-independent. Views are type-checked JSX.

component Counter(title: String) {
  state count: Int = 0

  view {
    <div>
      <h1>{title}</h1>
      <p>{count}</p>
      <button onClick={count = count + 1}>Increment</button>
    </div>
  }
}

7. Modules, not classpath hell

Explicit file-based imports. nova lock pins every dependency by hash — reproducible builds, no resolution algorithm.

import math_helpers

let r = math_helpers.clamp(150, 0, 100)   // 100

8. Concurrency the compiler understands

Single-threaded by default (no data races to fear). spawn opts into real parallelism for CPU work; async for IO. Blocking IO inside async code is a compile error — the language tells you what should be async.

async effect net fn fetchLen(url: String, net: Net) -> Int {
  let body = fetch(url, net).await()   // parks the tasklet, never the thread
  return len(body)
}

effect fn main() {
  let t = spawn { heavyCompute() }     // Task[Int], runs on the worker pool
  print(t.await())
}

9. Streams are first-class

Kafka-style pub/sub in the standard library: topics, consumer groups, offsets. In-memory locally; swap the provider for real Kafka in production — same code.

stream events: String

effect fn main() {
  let sub = events.subscribe(group: "workers")
  events.publish("hello")
  events.publish(key: "k1", value: "world")

  match sub.poll() {
    Some(msg) => print(msg.value),
    None      => print("caught up")
  }
}

10. AI as a language feature

An ai fn's return type is its output schema. The provider must return structured data conforming to your types — no prompt-roulette parsing.

data class Summary(headline: String, score: Float)

ai fn summarize(text: String) -> Summary
  model = "nova-mock-1"
  temperature = 0.3
{
  prompt("Summarize in one sentence: " + text)
}

11. Contracts you can read

requires and ensures are syntax, not comments. Intent becomes checkable.

fn divide(a: Int, b: Int) -> Int
  requires b != 0
  ensures result * b <= a
{
  return a / b
}

12. One manifest to deploy them all

app.nova declares threading, resources, secrets, cron and targets. nova deploy reads it — the manifest is the ops doc.

app "my-service" {
  version = "0.1.0"
  entry = "main.nova"
  threading = "auto"

  resource stream "events" { partitions = 4 }
  resource secret "db-password" { store = "env" }
  resource cron "nightly" { schedule = "0 2 * * *", run = "report.nova" }

  docker { base = "python:3.12-slim", port = 8080 }
  deploy target = "docker"
}

13. Errors built for AI

Every diagnostic is structured JSON with a stable code and a fix hint — designed for AI consumers first, humans second.

$ nova check broken.nova
[
  {
    "code": "E_NO_NULL",
    "message": "Nova has no null; use Option[T] (Some/None)",
    "line": 3, "col": 7,
    "hint": "return None instead, and handle it with match"
  }
]
